# Aion

Sistema pessoal para organizar o dia a dia em um só lugar.

## O que faz
- Reúne finanças pessoais, objetivos, agenda e nutrição.
- Permite registrar informações pela web ou pelo Telegram.
- Usa inteligência artificial para interpretar as mensagens.

## Stack
Next.js · React · TypeScript · Supabase · Vercel · Telegram

## Status
Em desenvolvimento. Código privado; este repositório é apenas uma vitrine.

## Serviços
Desenvolvo aplicativos pessoais e profissionais sob demanda e ofereço consultoria científica e tecnológica.
